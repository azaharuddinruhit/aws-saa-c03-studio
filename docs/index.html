How this is estimated
  • Your answers are fitted to an item-response (Rasch) model, so which questions you answered matters, not just how many you got right: a run of easy questions moves the estimate less than the same run of hard ones.
  • The model allows for guessing, using the odds of picking the right set at random from the options a question actually has — 25% on a four-option question, 10% on a Select TWO — so the estimate never credits you for a lucky guess.
  • Your fitted ability is then projected onto the real exam's own mix of easy, medium and hard questions, which is why practising only easy questions will not inflate your score.
  • Each domain is pulled toward your overall ability, so a domain with two answers isn't trusted like one with twenty. Domains are weighted by the official blueprint: 30% Secure, 26% Resilient, 24% High-Performing, 20% Cost-Optimized.
  • Recent answers count more (21-day half-life). Repeat attempts count 30%, answers taken after reading the hint count 45%, and mistake-drill answers count 50%, because each is weaker evidence of unaided ability.
  • A 3,000-run Monte Carlo simulates a 50-question scored exam and maps the result linearly onto AWS's 100–1000 scale, with 720 as the pass mark. Each run draws one shared ability plus a per-domain difference, because the domains rise and fall together, so the range is not artificially narrow. The range is the 10th–90th percentile.
  • AWS does not publish its scoring model or its item difficulties, so treat this as a guide rather than a guarantee.
