Exam Phrase Decoder

Most options in an SAA-C03 question work. The wording tells you which one the exam wants. Learn the phrases, the answer each one points to, and the trap it hides.

Constraints remove options. The MOST or LEAST qualifier picks between the ones that are left.

Hide the answers, then tap each one to check yourself.

Read every question in four passes

  1. 1Scenario

    Skim what is being built. It sets the domain but rarely decides the answer.

  2. 2Constraints

    Mark every must: private, highly available, within minutes, encrypted. Each one removes options.

  3. 3Qualifier

    Find the MOST or LEAST phrase. It decides between the options that still work.

  4. 4Eliminate

    Strike each option that breaks a constraint, then pick the survivor that best fits the qualifier.

Worked example

Question ALPHA-002 from Set Alpha.

ConstraintSymptom to fixQualifier

A payments API uses AWS Lambda functions behind Amazon API Gateway. The functions must read from an Amazon RDS for MySQL database in private subnets and also call a third-party fraud-scoring API on the public internet. During traffic spikes, the database reports 'too many connections' errors. The solution must be highly available and require the LEAST change to the database. Which combination of steps should the solutions architect take?

  1. A

    Attach the Lambda functions to private subnets and create an interface VPC endpoint for the third-party API. Set reserved concurrency to 1,000 so that the database gets a steady load.

    An interface endpoint reaches AWS services and PrivateLink services, not a third-party API on the internet.

  2. B

    Remove the Lambda functions from the VPC and make the RDS instance publicly accessible with a security group allowing all Lambda IP ranges. Increase max_connections on the database.

    A publicly accessible database breaks the security the private subnets imply.

  3. C

    Attach the functions to private subnets in two AZs with a NAT gateway in each AZ for internet access, and connect to the database through RDS Proxy.

    A NAT gateway per AZ gives highly available internet access, and RDS Proxy fixes the connections without changing the database.

  4. D

    Attach the Lambda functions to public subnets of the VPC, enable auto-assign public IPv4, and route 0.0.0.0/0 to an internet gateway. Increase the DB instance size.

    A Lambda function in a VPC never gets a public IP, so a public subnet gives it no internet access.

Phrase → answer pattern

The number on each card counts the questions in your four banks whose wording matches that group, out of 588.

MOST cost-effective

73 q
MOST cost-effectivelowest costminimize cost

PickMatch the price model to the usage: Spot for interruptible work, Savings Plans for steady load, serverless for spiky load, lifecycle or Intelligent-Tiering for cold data.

TrapCapacity sized for peak, or a more resilient design than the question asks for.

LEAST operational overhead

64 q
LEAST operational overheadfully managedminimal management

PickThe managed or serverless option: Lambda, Fargate, DynamoDB, Aurora Serverless, or a built-in feature such as S3 lifecycle rules or RDS automated backups.

TrapSoftware on EC2, cron jobs or custom scripts. They work, but someone has to run them.

Moving lots of data

49 q
petabyteslimited bandwidthminimal downtime

PickSnowball Edge for offline bulk transfer. DataSync for ongoing online copies. Storage Gateway when on-premises apps keep using files. DMS for databases with minimal downtime.

TrapCopying hundreds of terabytes over a slow link that would take months.

Secure and encrypted

43 q
encrypt at restcontrol and audit key userotate automatically

PickKMS customer managed keys when you must control or audit key use. Secrets Manager for automatic rotation. CloudHSM when you need a single-tenant HSM you manage.

TrapKeys or passwords in code, or SSE-S3 when the question asks you to control the key.

Highly available

37 q
highly availablefault tolerantsurvive an AZ failure

PickSpread across AZs: an Auto Scaling group in several AZs behind a load balancer, RDS Multi-AZ, and a NAT gateway in each AZ.

TrapA larger single instance, or a read replica treated as automatic failover.

Region failure and DR

24 q
Region outageRPO / RTOdisaster recovery

PickMulti-Region: Aurora Global Database, DynamoDB global tables, S3 Cross-Region Replication and Route 53 failover. Choose the DR strategy from the RTO and RPO.

TrapMulti-AZ, which never leaves the Region. Also active-active when a pilot light meets the RTO for less.

Real-time streams

19 q
real-timenear real-timeclickstream

PickKinesis Data Streams for real time with your own consumers and replay. Amazon Data Firehose for near-real-time delivery to S3, Redshift or OpenSearch without code. MSK for Kafka.

TrapA batch ETL job, or SQS when several consumers must read the same records.

Low latency and performance

18 q
global userslowest latencyread-heavy

PickCloudFront caches HTTP content near users. Global Accelerator gives static anycast IPs for TCP and UDP. ElastiCache, read replicas or DAX take read load off the database.

TrapA bigger instance in one Region when the users are spread around the world.

Credentials and access

15 q
temporary credentialsno long-term keysleast privilege

PickIAM roles everywhere: instance profiles, task roles, Lambda execution roles. IAM Identity Center for staff, and Cognito for app users.

TrapAccess keys stored on an instance, in code or in environment variables.

Decouple and absorb spikes

8 q
decoupleprocess asynchronouslyfan out

PickSQS buffers work (FIFO for order). SNS to several SQS queues fans out. EventBridge routes events by rule, from AWS, SaaS or schedules.

TrapDirect synchronous calls between tiers, which fail together.

Minimal changes

7 q
without code changesminimal changeslift and shift

PickThe managed version of what already runs: RDS for the same engine, Amazon MQ for ActiveMQ or RabbitMQ, FSx for Windows for SMB, Application Migration Service to rehost.

TrapA rewrite to SQS, DynamoDB or Lambda. It may be better, but it is not minimal.
