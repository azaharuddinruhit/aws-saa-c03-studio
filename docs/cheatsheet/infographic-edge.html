Edge and DNS

How users reach your application: CloudFront or Global Accelerator at the edge, and the Route 53 routing policy that decides where each user goes.

Cache HTTP with CloudFront, and give TCP or UDP static IPs with Global Accelerator. In Route 53, pick the routing policy from what the question optimizes: speed, location, weight or failover.

Route 53 routing policies

Simple

One record with one or more values, and no health checks.

Exam cuea single resource

Weighted

Splits traffic between records by weight.

Exam cueblue/green · send 10% to the new version

Latency

Answers with the Region that gives the user the lowest measured latency.

Exam cuefastest Region for each user

Failover

Sends traffic to the primary while its health check passes, else to the secondary.

Exam cueactive-passive · DR site

Geolocation

Answers by the user’s continent, country or US state. Add a default record for everyone else.

Exam cuecontent by country · data must stay in a country

Geoproximity

Answers by distance between user and resource, and a bias grows or shrinks each resource’s area.

Exam cueshift traffic between Regions by distance

Multivalue answer

Returns several healthy records at random, so clients spread their load.

Exam cuesimple load spreading with health checks

IP-based

Answers by the client’s IP range (CIDR block).

Exam cueroute by ISP or known network

Alias records

Point a name, even the zone apex, at CloudFront, a load balancer, an S3 website or API Gateway. A CNAME cannot sit at the apex.

Health checks

Check an endpoint, combine other checks, or follow a CloudWatch alarm for resources Route 53 cannot reach.

Private hosted zones

Names that resolve only inside the VPCs you associate.

Resolver endpoints

Inbound endpoints let on-premises DNS resolve AWS names. Outbound endpoints forward AWS queries to on-premises DNS.

Resolver DNS Firewall

Blocks or allows the domains that resources in your VPCs may look up.

TTL

Lower the TTL before a migration or failover test, so clients pick up a changed record quickly.
